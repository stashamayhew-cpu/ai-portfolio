Project context

The challenge and solution

The challenge

Employees can recognize a frustrating manual task without knowing which application or workflow to use. Jumping to a product recommendation without requirements discovery can lead to a poor fit.

My approach

I designed WorkSmart Advisor to start with the business need, ask targeted questions when necessary, recommend practical Microsoft solutions, and provide setup, testing, and deployment guidance.

Solution design

From request to implementation

01 · Discover

Understand the need

Explore request types, approvals, communication, and process requirements.

02 · Recommend

Choose tools intentionally

Evaluate options such as Microsoft Lists, Forms, SharePoint, Teams, and Power Automate.

03 · Implement

Guide the build

Offer actionable steps, permissions checks, testing considerations, and follow-up support.

Behind the scenes

How I configured the agent

My work included defining the agent's purpose, writing behavioral instructions, configuring an Implementation Coach tool with AI-populated inputs, and evaluating example conversations.

Design decisions

What this project demonstrates

Intentional agent behavior

Instructions prioritize understanding requirements and recommending an appropriate solution rather than naming an application immediately.

Responsible guidance

The Implementation Coach instructs users to verify administrative and product-specific details, and to prototype and test business-critical solutions before deployment.

What's next

WorkSmart Advisor 2.0

Planned next phase: an independent AI business process and automation advisor that analyzes current workflows, identifies improvement opportunities, compares AI and traditional automation, and helps plan implementation. These are future goals, not claims about features already shipped.
