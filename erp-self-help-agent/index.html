ERP Self Help Agent

Conversational ERP guidance with escalation to IT support

Professional experience
Context and approach

The challenge

Common ERP questions can interrupt staff and support teams. Employees need clear self-service guidance as well as a reliable path to ask for help when a question remains unresolved.

My approach

Built an agent that provides procedural guidance for common ERP support questions and offers to initiate a Freshservice support request when self-service is insufficient.

Work and contributions

What I worked on

Conversational guidance

Developed an ERP-focused AI assistant in Copilot Studio to help staff find actionable guidance within a familiar conversational experience.

Support escalation flow

Connected the agent to a Power Automate process that collects support-request details and uses an Outlook email action for Freshservice intake. This is the implemented fallback design, rather than a direct Freshservice ticket API claim.

Testing and troubleshooting

Iteratively tested conversation behavior, fallback prompts, authentication constraints, and flow inputs; investigated integration and schema errors during development.

Human-centered design

The agent supports existing help-desk operations rather than replacing technical support staff. Users can still seek help for unresolved or complex cases.

Example interaction

How the agent supports employees

A user asks, “How do I post an invoice?” The ERP Self Help Agent responds with structured instructions for posting a purchase-order-related vendor invoice. The example covers locating the received PO, generating the invoice, checking invoice details and match status, submitting for approval, and posting after approval.

Input: natural-language question

Employees can ask everyday ERP questions without knowing the exact title of an internal guide or the system navigation path.

Output: actionable next steps

The agent organizes process guidance into clear numbered steps and distinguishes purchase-order invoices from non-PO invoices or invoice journals, where workflows differ.
